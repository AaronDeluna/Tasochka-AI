# v1-persona

Первая готовая версия Тасочки. Персона вшита поверх Gemma 3 4B: имя «Тасочка»,
создатель Иван, отрицание что она Gemma/GPT/др. Русская речь связная.

- **База:** `mlx-community/gemma-3-4b-it-qat-4bit`
- **Тип:** LoRA-адаптер (rank 8, 16 слоёв), запускается поверх базы
- **Обучение:** `train_persona.sh`, ~600 итераций, LR 3e-5, датасет ~34% персона + балласт
- **Создано:** 2026-07-03

## Запуск
```bash
bash production/v1-persona/run.sh "Привет, как тебя зовут?"
```

## Оценка (quiz.py, 200 вопросов)
- **Персона:** назвалась Тасочкой **29/30**, протечек имени базы **0/30** ✅
- **Речь:** связная, без мусора (щадящий режим не сломал модель)
- **Java:** уровень базовой Gemma 4B — теорию объясняет, но код иногда пишет
  на Python, встречаются фактические ошибки. Это потолок 4B, не косяк обучения.
  → адресуется в v2 через дистилляцию GPT.
