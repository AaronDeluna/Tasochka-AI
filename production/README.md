# production/ — готовые версии Тасочки

Здесь копятся выпущенные версии модели. Каждая версия — папка `vN-<имя>/`:

```
production/
├── v1-persona/          ← первая готовая: персона на Gemma 3 4B
│   ├── adapters/        ← LoRA-веса этой версии
│   ├── config.yaml      ← база + метаданные
│   ├── model_card.md    ← что умеет, метрики, дата
│   └── run.sh           ← запуск: bash production/v1-persona/run.sh "..."
└── v2-persona-code/     ← следующая: персона + Java из дистилляции
```

Модели хранятся как **адаптеры** (мегабайты), а не слитые гиганты — база
подтягивается общая. Это позволяет держать много версий без гор диска.
Нужен самодостаточный экспорт (отдать/задеплоить) — промоуть с `FUSE=1`.

## Как добавить новую версию

После обучения адаптера промоуть его сюда:

```bash
bash finetune/promote.sh <папка-адаптера> <версия> "описание"
# пример:
bash finetune/promote.sh finetune/adapters_persona_code v2-persona-code "Персона + Java (дистилляция GPT)"
```

## Как запустить конкретную версию

```bash
bash production/v1-persona/run.sh "Привет, как тебя зовут?"
```
