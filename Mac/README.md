# Локальные эксперименты на Mac

Прежняя реализация перенесена сюда вместе с пакетами, утилитами, UI и LoRA-экспериментами. Новое серверное обучение находится в `../server/` и не импортирует MLX.

```bash
cd Mac
bash setup.sh
source .venv/bin/activate
python download_datasets.py --help
python -m tasochka.train --help
python -m tasochka.generate --chat
```

Если до переноса уже были данные/веса в корне репозитория, перенесите свои `checkpoints/` и `russian-train-dataset/` в `Mac/` либо задайте явные пути через `--checkpoint` и `--data`. Файлы весов не содержатся в Git и автоматически не конвертируются в новую 3B-модель.

`RUN_MAC.md` — локальные команды. `LEGACY_SERVER.md`, `TRAIN.md`, `CONTEXT.md` и `eval_output.txt` — исторические материалы старого эксперимента: оценки скорости и качества оттуда не относятся к новому серверному пайплайну. В старой реализации resume может восстанавливать только веса; полное состояние обучения реализовано в `server/`.

`finetune/` — отдельный прежний опыт с чужой базовой моделью и MLX LoRA. Он не входит в серверный сценарий обучения собственной модели с нуля.
